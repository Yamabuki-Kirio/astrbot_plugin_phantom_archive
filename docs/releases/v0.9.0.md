# 夜幕档案 v0.9.0

本版本扩展每日运势玩法，支持指定角色与特殊形态，新增“今日课题”，并进一步优化三套背景中的人物立绘尺寸。

## 主要更新

### 指定角色抽取运势

所有运势指令现在都支持可选角色参数：

```text
运势 双叶
p5x运势 sp素羽
p5x运势 周星驰
/p5x每日运势 平野亚兰凛华
```

不带角色参数时继续随机抽取。指定角色后，卡片会使用该角色对应形态的人物立绘和人格面具立绘。

普通形态与特殊形态严格区分：

- `素羽` → 新井素羽；
- `sp素羽`、`素羽sp` → 新井素羽·晴光；
- `夏日素羽` → 新井素羽·夏日；
- `周星驰`、`星舞雨宫莲` → 雨宫莲·星舞；
- `平野亚兰` → 原版四星；
- `sp平野亚兰`、`平野亚兰凛华` → 五星 SP 形态。

指定角色采用严格匹配，只接受正式名称、代号和已登记别名。未知名称不会模糊猜测，也不会回退到其他形态或随机角色。

### 新增“今日课题”

每日运势由“角色 + 塔罗吉凶”扩展为三项内容：

1. 随机或指定角色；
2. 塔罗牌、正逆位、吉凶及宜忌；
3. 今日课题及行动提示。

今日课题包含学业、工作、财运、社交、恋爱、健康、创作与冒险八类。课题使用独立确定性种子，同一用户当天结果固定，调整角色池不会改变当天的塔罗或课题。

### 卡片布局与立绘尺寸

- 三套背景均增加“今日课题”独立模块，并重新适配纵向间距、字号和信息板高度；
- 修复 P3 蓝色背景在新增模块后可能出现的内容溢出；
- 自动识别角色+武器、长武器或宽特效构图，使用更大的立绘容器；
- 人物与人格面具继续使用独立图层，放大后不会遮挡左侧运势内容。

### 新五星角色

- 新增五星 SP 角色“平野亚兰凛华”；
- 新增高清透明人物立绘与超分人格面具立绘；
- 新增官方角色资料图入口；
- 原版四星平野亚兰继续独立保留。

## 兼容性

- 无参数运势指令行为保持不变；
- 旧的 `p5x_daily.sqlite3` 运势记录可以继续读取，缺少“今日课题”的旧记录会按原日期和用户身份确定性补算；
- 带 `/` 指令始终可用；无斜杠写法需要开启 `enable_plain_commands`；
- 指令与角色参数之间必须保留空格。

## 验证

- 指定角色、普通/SP/星舞/夏日形态与趣味别名均有测试覆盖；
- 三套背景已使用双叶、素羽·晴光、雨宫莲·星舞、YUI·幻彩、多祢村理子·未央等不同构图实际渲染；
- 运势、角色检索、背景、人格面具与立绘尺寸相关定向测试通过；
- 完整测试为 602 项通过、71 项因缺少 AstrBot 运行时跳过；仍有 1 项既有合成图尺寸断言要求旧版 720×960，与本版本功能无关；
- 素材清单共校验 427 个文件，角色立绘覆盖 73/73，武器图片覆盖 139/142。
