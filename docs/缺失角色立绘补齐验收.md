# 缺失角色立绘补齐

本次检查时，素材清单为 70/72 名角色有立绘，实际缺少荒垣真次郎和天田乾。
README 中的 69/72、113 张是旧数据。本次完成后为 72/72、75 张。

## 来源与处理

- 来源：ATLUS《女神异闻录3 Reload》官网 https://p3re.jp/ 的角色介绍。
- 使用两人的常服全身人物图；这是 P3R 官方立绘，不宣称是 P5X 专用立绘。
- 原图地址、原图 SHA256、原作品与处理方式写入 `data/assets/manifest.json`。
- 保留原生透明通道，裁去透明留白，全身等比放入 720×960 画布，WebP quality=92、alpha_quality=100。
- `scripts/fetch_missing_portraits.py` 可以重新下载并生成这两个角色的文件，不改其他角色映射。

## 本地验证

- `scripts/verify_assets.py`：72/72 角色有图，75 张立绘，361 个引用文件检查通过，无警告。
- `tests/test_asset_manifest.py`、`tests/test_asset_resolver.py`：36 项通过。
- 使用正式每日运势 HTML 模板，经 Edge 无头浏览器生成并检查两人的深色、浅色预览：全身完整，透明底正常。
- 图片文件随插件打包，运行时无需访问来源网站。
