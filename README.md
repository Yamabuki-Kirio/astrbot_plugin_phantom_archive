# 夜幕档案

`astrbot_plugin_phantom_archive` 是面向 AstrBot 的《女神异闻录：夜幕魅影》中文资料查询插件。

> 当前状态：开发占位版。仓库结构已经建立，实际资料查询功能尚未接入。

## 规划功能

- 角色、技能和意识查询
- 武器属性及效果查询
- 中文配队与养成建议
- 国服官方公告查询
- 图片攻略卡片

## 当前可用指令

```text
/p5x
```

该指令只返回开发状态。

## 数据说明

- 国服公告计划来源于 P5X 完美世界官方网站。
- 角色与攻略资料需要经过中文规范化和来源标注后才会接入。
- 原始抓取文件及社区资料数据库不会提交到本仓库。
